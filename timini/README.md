# Timini English Private Institute Website

A responsive recreation of the supplied Timini English Private Institute landing-page template using only:

- HTML5
- CSS3
- Vanilla JavaScript

## Files

- `index.html` — semantic page structure
- `style.css` — responsive styling, layout, animations
- `script.js` — navigation, smooth scrolling, reveal effects and back-to-top behavior
- `assets/` — reserved for local images/assets

## Run

Open `index.html` directly in a modern browser.

No build process or framework is required.

## Notes

The design uses CSS illustrations for the hero and Talking Pen areas so the project remains lightweight and self-contained. Google Fonts are referenced externally for typography; the browser will gracefully fall back to system fonts if unavailable.
