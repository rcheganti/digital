KOKAPET LUXURY VILLAS WEBSITE
==============================

Files:
- index.html  -> Main website
- style.css   -> Full responsive design
- script.js   -> Enquiry form + WhatsApp integration
- hero-poster.png -> User-supplied project poster

HOW TO USE:
1. Extract the ZIP.
2. Open index.html in Chrome.
3. Upload the whole folder to your hosting/cPanel/Netlify/Vercel.
4. Replace the WhatsApp number in index.html and script.js if needed.
5. Replace/add project photos as required.

IMPORTANT:
- Project facts used: Kokapet, starting plot area 200 sq. yards, approx. 3,560 sq.ft., 19+ amenities, ₹4.5 Cr* shown in the supplied poster.
- The site uses placeholders such as "19+" and "subject to confirmation" where exact project documentation was not supplied.
- The enquiry form opens WhatsApp; it does not store leads in a database.
